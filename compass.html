🧭 Modes

🧭 Compass Mode 📍 Points Mode
C
Press C to toggle between modes
🧭 Compass Mode (compass visible)
1
Position the compass — Move it so the long edge aligns between two points on the map
2
Rotate the bezel — Turn the bezel until the red orienteering lines in the top half point north, parallel to the map's red north lines
3
Read the bearing — The number at the red index line on the compass is your bearing in degrees
📍 Points Mode (compass hidden)
1
Click a start point — The point turns green
2
Click an end point — The point turns red
3
Read the computed bearing in the info panel — no compass needed!

🧩 Compass Anatomy

Direction of Travel Arrow — point this at your destination
Index Line — read bearing here
Bezel Ring — degree markings for bearings
Orienteering Arrow — points to N on the bezel, fixed in place inside bezel
Orienteering Lines (Red top, Black bottom) — align with map grid
